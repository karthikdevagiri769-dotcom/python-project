🎁 Python Rakhi Surprise Project

A simple and interactive Python-based surprise application designed to create a memorable Raksha Bandhan experience. The application allows users to enter two names and presents a suspenseful reveal with a Rakhi-themed image, background music, and a heartfelt closing message.

✨ Features

- Name Input: Enter two names to personalise the surprise.
- Suspenseful Reveal: Displays an engaging name-reveal experience.
- Image Display: Automatically displays a Rakhi-themed image.
- Background Music: Plays Rakhi-themed audio during the experience.
- Interactive GUI: Simple and user-friendly graphical interface.
- Replay Option: Allows users to experience the surprise again.

🛠️ Technologies Used

- Python 3
- Tkinter – Graphical User Interface
- Pillow – Image Processing
- Audio Playback

⚙️ Installation and Setup

1. Clone the repository

git clone https://github.com/YOUR-USERNAME/python-rakhi-prank.git

2. Navigate to the project folder

cd python-rakhi-prank

3. Install dependencies

pip install -r requirements.txt

4. Run the application

python rakhi.py

💡 Purpose

This project demonstrates how Python can be used to develop interactive desktop applications by combining graphical interfaces, multimedia elements, and user input.
